Rationale and exception
-----------------------
The catalog's native TTF convention names Truth in Testimony Disclosure Forms.
The publisher-house-disclosure rule recognizes the complete Truth-in-Testimony
phrase under its allowed House publisher hosts. document_category_fields lets
the complete phrase own its nested generic testimony label. That explains why
the current filename result is disclosure rather than a witness statement.
The Montgomery Disclosure aliases match the same publisher-qualified category.
All original wording, source membership and retained body histories stay intact.

selection, all filenames, per-source extraction audit and implementation files.

not_performed and release_approved as false.

has an alias integrity issue. All nine frozen PDF experiment source hashes are

review evidence only, so it does not require repeating the runtime test suite.

annotations have been joined and validated. No release approval follows from
