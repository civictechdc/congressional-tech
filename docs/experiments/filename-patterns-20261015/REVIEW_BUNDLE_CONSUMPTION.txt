Pinned local bundle consumption: self-review
============================================
Findings
--------
No blocking finding within the exact-baseline local reader. A bundle from another
path/snapshot or admission implementation is deliberately refused, even if its IDs
look familiar. The expected summary hash must come from verified admission; hashing
an arbitrary producer's file is not an authenticity check. Viewer/publication
adoption remains outside this patch.

Data flow and invariants
------------------------
H1: A generic bindings map alone identifies which two files were the admission
baseline. Refined: it also contains historical input pairs. The writer now records
explicit baseline roles and format version; the reader requires both roles and
their matching entries in bindings. Old unversioned outputs remain preserved and
must be regenerated through admission, not edited to bypass version checks.

H2: Output hash verification alone guarantees a saved candidate still fits current
rows. Refuted for changed baselines; the reader re-applies the compiled review to
complete current members and compares all semantic candidate fields. It rejects
scope changes and unsupported result statuses rather than silently dropping review.
Only null dictionary padding is ignored; list order and all non-null fields remain
significant. Every select_document call repeats that check for current in-memory
rows. Results are detached from both baseline and saved candidate map.

H3: Inputs may change during loading. Guarded: every bound file and implementation
identity is checked again before returning candidates. Loading is read-only. The
consumer must reload when its baseline snapshot changes; it must surface refused
bundles rather than quietly interpreting a failure as withdrawal. Explicit omission
is the withdrawal operation and preserves the caller's current baseline exactly.

Limits and next steps
---------------------
This is a local format with historical filesystem references. Every load hashes
all bound evidence files, so loading belongs outside the per-document render path.
No independent rereading of PDF contents occurs; receipt admission remains the
source of verified coverage and assistant provenance. A portable publication format
and an independent reference remain separate requirements.

Next run admission and consumption against the complete saved catalog pair while
selecting the same reviewed groups. Measure the actual selected-row read/memory
behavior, verify all excluded baseline bytes stay unchanged, and report any new
binding transition explicitly. Do not treat selected-group qualification as a full
classification refresh. Then resolve unsupported packet representation and portable
evidence references before viewer or publication integration.
