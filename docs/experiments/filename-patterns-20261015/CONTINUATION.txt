Native conventions and boundaries
---------------------------------
1. Complete PLAW-<Congress>publ<number>.pdf names on GovInfo, GPO and Congress.gov
   supply public-law, grouped under legislation. Private laws and suffixed
   summaries are outside this rule. Law and Congress tokens remain literal.
2. Complete House H<number>[office]_RH_xml.pdf names on docs.house.gov supply
   legislative-text. Existing measure/version readers retain their meanings.
3. Complete House H<number>_SUS_xml.pdf names on docs.house.gov supply
   legislative-text. SUS remains local wording, not an official version or a
   verified passage/suspension event.
4. Complete three-digit/dash/number PDF names on Financial Services supply
   published-hearing. serial_token preserves the filename's literal spelling;
   it does not establish Congress or a GPO publication number.

The 103-3.pdf cover prints serial 113-3 and the 113th Congress. This discrepancy
is retained explicitly and tests prevent Congress inference from these names.
Unknown publishers, XML/media outer extensions, summaries and amendment suffixes
do not receive these new kinds. The general filename algorithms are unchanged.

Source-association recovery
---------------------------
All 802 document groups with recognized labels carried through unproven URL
variants were inventoried: 1,026 relevant anchor occurrences. None of their
original URLs appears in the frozen document source URLs. The local capture
snapshot also provides no exact URL/body matches, but ends on October 2 and
predates these associations; this is not evidence about the current R2 catalog.

A separately frozen sample of 48 unique original URLs spans publisher/kind
strata. Outcomes: 14 HTTP 403, 14 HTTP 404, 10 HTTP 410, and 10 read failures.
No PDF was returned and no source association was promoted. This sample does
not prove that all 802 are unrecoverable. Current retained capture receipts or
archive evidence are the next recovery inputs; guessed replacements remain
untrusted. Existing source-association trust policy was not weakened.

Prepared content pilot
----------------------
The pilot freezes 400 still-unclassified PDFs, split into 200 development and
200 held-out records. Selection balances publisher, filename-family and retained
body presence, with deterministic hash ranking. Native candidate families and
previously reviewed bodies are excluded. No retained body repeats within or
across the splits. It covers 284 strata and is not population-weighted.

pilot-review.csv contains blank reference-label and evidence fields. pilot.json
retains document IDs, source URLs, body keys, split and selection strata. Text
availability is explicitly not_checked; this is a prepared review set, not a
completed labeling exercise or performance benchmark. Failed retrievals must
stay in the sample. Use development examples to tune extraction/classification;
keep held-out reference labels separate until evaluation.

Reproduce
---------
Use the Python environment with PyArrow and the package sources from this tree:

  export PYTHONPATH=packages/house-naming/src:packages/congress_api/src:packages/congress_shared/src:packages/committee_meeting/src

continuation.py OUTPUT creates a new immutable selection directory from the
frozen documents.parquet and integration-v3 baseline. --boundaries prepares its
additional native sample. --capture-index PATH audits an existing capture index.
content_validation.py publishers --output OUTPUT/native-content and the same
command for native-boundary-content retain publisher retrieval receipts and PDFs.
association_probe.py OUTPUT freezes and checks up to 48 original source URLs.
These experiment scripts do not write capture state or catalog classifications.

integration_audit.py OUTPUT/replay runs the maintained readers over the frozen
population. continuation_report.py checks the recorded continuation-v1 artifacts,
all retrieved PDF hashes, complete ID conservation, earlier classifications,
pilot separation, current code fingerprints and test logs, then builds the report.
Use a new output directory for a new selection; do not overwrite the frozen set.
