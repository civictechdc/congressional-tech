Tests and verification
----------------------
New tests (test_document_review_portable.py) delete all original files, alter the
earlier store's reader policy and re-admit against a copied pair at a new path.
They require byte-identical candidates, original locator text, a loadable new
store and refusal of unmapped locators. Altered objects, a wrong manifest pin and
a removed locator are refused before output.

Executed evidence is in output/filename-patterns-20261015/review-rebind-v1 and
review_rebind_checkpoint_v1.json. It covers reconciliation, strict comparison,
admission, portable export, viewer snapshot and public export. The 1,039
alias/filter search checks pass over the new pair, and original and reviewed
all-record counts are both 1,241,131.
A read-only static-reader check over the live public catalog resolves all 286
reviewed sources by stable source ID through the live ID index. Each matches its
reviewed selection and withdrawal. Reviewed mode moves Neal-3938 from amendment
to committee-vote. The live site still serves the c5e4c563 file bound to d42b9f,
so reviewed search there remains dark until deployment.
