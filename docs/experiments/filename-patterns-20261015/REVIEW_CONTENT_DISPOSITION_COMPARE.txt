Data flow and invariants
------------------------
run reads proposals without editing them, then constructs selected source and
document maps. compare_case only reads these maps and returns new dictionaries;
the input-preservation assertion is at test_catalog_disposition_compare.py:35.
The requested ID set must equal the full needs_review set, not a selected subset
(catalog_disposition_compare.py:105). Each source belongs to the exact original
membership, and both the proposal and receipt bind the complete original row
(lines 45-69). A body replacement at the same URL cannot inherit the proposal.

Unavailable cases carry null differences rather than empty-set agreement
(lines 71-85). Missing native content is recorded as absent even when filename
labels match the review. Primary and component forms are compared together;
no production taxonomy mapping or silent synonym normalization occurs.
Bindings are rechecked before writes (line 123). Output paths must not exist
(line 91); the original ledger and catalog files are never write targets.
