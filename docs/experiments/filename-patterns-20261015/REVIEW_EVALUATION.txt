Reference and evaluation workflow review
=======================================

Findings first
--------------
No blocking defect remains in the reviewed local workflow. The review and
development execution support using it for controlled reference collection and
evaluation. They do not qualify any classification rule for production.

Resolved correctness finding: the initial new evaluator built rule decisions
only from candidate/reference kinds. A baseline kind could therefore disappear
from rule decisions when the candidate abstained and the reference was uncertain.
pilot_evaluate.py:179-187 now includes every changed baseline kind.
test_pilot_evaluate.py:136 exercises that exact loss without a usable reference.

Operational limitation: pilot_evaluate.py:208-211 deliberately refuses another
held-out run after its start marker exists. Interrupted output requires explicit
inspection and recovery; automatic resume is not implemented. That limitation
is documented in REVIEW_WORKFLOW.txt and tested at test_pilot_evaluate.py:198.

Evidence limitation: reference labels are assistant-reviewed. The publication
rebuild was still running at this checkpoint, so no real held-out packet or
evaluation was produced. Synthetic held-out tests prove local checks, not live
publication or independent reference quality.

Data flow and invariants
------------------------
H1: a historical subset cannot unlock held-out review. CONFIRMED: standalone
reconciliation sets paired_catalog_validated=false, and the held-out validator
rejects its summary before reading pilot evidence. A verified selected manifest
must agree with both public manifests and the saved publication readback.

H2: every frozen selected ID remains accounted for. CONFIRMED: reconciliation
iterates the original selection; packet construction preserves split order;
checked_references creates one output per packet record. Missing available
decisions block sealing. Unavailable/visual/changed records retain explicit
states and empty reference kinds, not substituted samples.

H3: labels and evidence cannot silently change between review and comparison.
CONFIRMED for the supported local workflow: source, sample, packet/interface,
quote, PDF, journal and runtime checks run before evaluation. The label-freeze
hash is rechecked after evaluation. New imports cannot alter a sealed reference
set. These are integrity checks, not cryptographic proof of who reviewed text;
the tool always preserves human_validated=false.

H4: failures and missing evidence cannot inflate agreement. CONFIRMED:
summarize distinguishes not_run, reader errors, successful abstentions, scored
assignments and unscored assignments. Changed prior kinds include lost kinds and
candidate errors. The interval denominator contains scored assignments only;
missing/unscored evidence is reported separately. Every rule retains
automatic_release=false regardless of sample results.
