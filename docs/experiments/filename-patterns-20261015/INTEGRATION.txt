Document-kind hints integrated locally — October 15, 2026
========================================================

Result
------
The maintained readers assign kinds to 9,427 previously unclassified document
groups, covering 9,410 distinct filenames. Filename and publisher rules supply
6,142 assignments; attributable source context supplies 3,285. The replay resolves
28.1% of the 33,548 records admitted by this experiment's document-role gate.
This is an 80/20 pass over usable hints, not 80% resolution of every unknown.

All 657,103 frozen IDs are conserved. The 623,555 records flagged for role review
are separate from the 24,121 eligible unresolved records. These include 464,498
media/image records, 143,422 meeting/package XML records, 15,553 HTML records,
45 event/index endpoints and 37 archives. A role flag is not a deletion decision.

The local code is integrated and tested. No production catalog was rebuilt or
published. The original full catalog parquet is no longer present locally, so
this report does not claim coverage of unnamed records or the full catalog.

Implementation
--------------
house-naming catalog 3.1.0 adds 15 publisher-qualified literal filename layouts.
They retain wording spans, dates, identifiers and strict validation behavior.
Allowed outer extensions prevent a name such as hearing_memo.pdf.jpg from taking
a new document kind. Existing official naming slots are not repurposed.

The index reader calls document_label_kind only as a missing-kind fallback.
Existing filename, content and typed-source meanings retain their precedence.
The fallback considers source_occurrences, never an unpaired flat label union.
It requires official House/Senate publisher pages and attributable anchor links;
legacy anchors without association-basis metadata must match an exact known
source URL. Unknown or disagreeing considered claims abstain. User-accepted URL
variants do not prove the associated page label describes the fetched document.
Source-derived kinds are cleared and recomputed during cached source refresh.

Primary-kind convention: describe purpose. A hearing notice can be formatted as
a memorandum; an opening statement can appear in a press release; a witness list
can contain an agenda. Keep the underlying wording and source claims. The new
hearing-charter kind identifies explicitly titled charter documents. Filename
inference never asserts that a particular matched body was reviewed.

Stopping decision and path forward
---------------------------------
The prior integrated pass found 9,180 assignments. The last bounded extension
adds 247, a 2.7% increase; it changes no previously assigned kinds. Inspection of
all 100 filenames and available labels in the deterministic remaining-PDF sample
shows many surname/date/number filenames, generic labels and uncertain associations.

Of 829 remaining records with recognized source-label hints, 802 have a known
hint attached through an unproven URL variant. Recover exact page-to-document
associations before using those labels. This count is diagnostic, not a claim
that all 802 would classify after recovery; other occurrences may still disagree.

There are 13,825 unresolved PDF-format records and 9,724 XML-format records.
The remaining broad filename searches include 358 amendment-like names, 183
malformed statement slots, 123 opening-like names, 97 vote-like names, 80 memo-like
names, 68 testimony-like names and one SSM addendum. These overlap and include
topic mentions, other document forms and ambiguous publisher conventions.

Keep these deferred rather than treating every matching word as the document's
kind. Follow-up work can combine body/title extraction, verified source recovery,
and native publisher formats: for example, 42 PLAW names and 168 abbreviated bill
PDF names remain recognizable leads. The 655 numbered hearing-like PDF names
need publisher/content qualification. Science WState filenames can describe
members, so that malformed slot must not automatically imply witness role.

This completes the high-yield hint pass. Full retained-source rebuilding,
publication and the broader content-classification phase remain separate work.
