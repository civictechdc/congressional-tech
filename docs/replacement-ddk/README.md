# Congressional-tech DDK replacement

The greenfield replacement is in progress. All producers and consumers will
move together to one public DDK catalog format. Old reader decoders, metadata
fallbacks and importers for old controller state are outside the scope. Reuse
valid retained originals and native results; preserve exact data meaning and
new-stack recovery, qualification, protection and release membership.

The reverse registry converter has been removed. Direct MCP/browser catalog
consumers, one native request builder and one retry-safe post-native finalizer
are implemented in source. The complete managed caller, candidate qualification,
acceptance against a replacement-produced native release and retirement of
superseded production paths remain open.
No full replacement, external publication or production cutover is complete.
