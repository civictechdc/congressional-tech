# S1 shared byte classifier

The shared sniffer covers all fourteen DM format values from bytes: PDF, ZIP, XML, HTML, JSON, VTT, M3U8, Open XML/OpenDocument packages (`docx`), legacy Office/RTF (`doc`), text, images, WARC/ARC, other and empty. Names and media types never enter its interface. The S1 checkpoint remains open for the semantic SQL, registries, labeled sample and real-slice qualification.

Contracts `f75f3f36`, `eb5c98c9`, `750a1819`, `3d02ec5f` and `e8803a5f` precede the binding. The project runner passes **89 tests** across the sniff, page, archive and existing PDF reader/file suites (`cx_s1_fold_shape_checks.log`). The last full offline lane, before the original-gzip correction, passes 11,368 tests with 33 failures and 3 setup errors, exactly the same 36 failure identities as the baseline, including five subtest failures (`cx_after_s1_sniff_full_comparison.json`). It started at `8c731589`; the runtime binding is `35315b74`. The tests use actual Poppler for readable PDFs without end markers, binary preambles and truncation; injected adapters check exact range requests and reader/storage refusals. Contract `8ce657dd` also checks the native empty display-facts fold: the page readers already return a list; sniff now does too. No bucket was accessed and no full PDF population was read.

Ordinary bodies use one 8 KiB prefix. Bare PDFs also use the last 8 KiB, then the bounded reader only if no end marker exists. A fallback reuses both ranges; PDFs beyond the 16 MiB reader limit receive `intact=false` and `pdf_reader_size_limit`. Older gzip PDFs retain null integrity, allowing the model to borrow recorded checks and defer the rest until B13. WARC/ARC detection reads through a second gzip prefix without expanding the whole archive. Contract `b6e6106e` keeps every other gzip original as `other`, rather than falsely claiming bare-PDF integrity or ZIP expansion; removing storage compression is a separate operation. The version digest includes the source helpers, locked dependencies and installed PDF-reader identities.

ZIP classification reuses the bounded retained archive inspector: a 64 MiB archive, 1 MiB central directory and 1,024 entries. Open XML checks the exact root `[Content_Types].xml`; OpenDocument reads at most 256 bytes from a bounded root `mimetype` entry. Generic or nested names do not create an Office package. Corrupt or unsupported ZIPs produce `error`; size refusals produce `size_limit`. This S1 implementation currently materializes a bounded ZIP; B2 still must adapt the archive expander to its captured file. Memory grows with the declared archive or PDF-reader bound, not the number of capture addresses; work is linear in the bytes read and directory entries.

DM §5.2 now resolves its contradiction with the oversized-PDF acceptance fixture: a required read refused for size is explicitly damaged and reported apart, while an unexamined older gzip PDF remains unchecked. DM §6.2 states the ZIP read exception and bounds. The page parser now uses DM §6's `error` status for rejected input. Storage failures raise a sanitized read error and create no parser row; PDF tool/resource failures require the producer's retry/settlement path, rather than becoming damage verdicts. D2 must qualify that supervisor and its work-list behavior.
