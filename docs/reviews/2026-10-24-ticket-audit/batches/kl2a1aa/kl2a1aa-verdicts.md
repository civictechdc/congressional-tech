## Severity ranking with greenfield priorities

Only raw/source data matters: R2 bodies, receipts and provenance. Derived data and compatibility rank low. Verdicts and grades above are unchanged.

**Raw-data risks, most severe first:**

1. **The public raw bucket (ct-te1p, ct-84xa).**
   - The custom domain exposes the whole `congressional-tech-raw` bucket, so one WAF expression is the only barrier in front of receipts, indexes and state.
   - That expression allows more than the tests check: any `/viewer-publications/*` except `accepted-*`, and any `/exports/*` (edge json:35). The tests use a stricter simulator (r2_edge_rules.py:83-103).
   - `apply` PUTs the zone-wide entrypoint rulesets (apply_r2_edge_rules.py:278, 284).
   - The exclusion gate fails open: its default file has never existed (raw_storage.py:76-83, 134-137), and raw_sync does not wire it (raw_sync.py:320-325). Excluded bodies are therefore never quarantined.
   - Live state is unverified.
2. **news_lake production writer (ct-1h4g, ct-a1aa).**
   - `DocSpecLake.commit_records` never checks the fencing epoch (lake.py:498-575; `fenced_commit` has no callers), so a stale writer can commit tables and rewrite committed state.
   - The manifest and state are written with `fsync=False` before the release is marked available (lake.py:744-758).
   - The crash matrix covers only the Iceberg oracle.
3. **body_key provenance became code, not data.**
   - Raw tables no longer store `body_key`; it is derived from sha256 at read time (raw_schemas.py:176-205; raw_storage.py:538-547).
   - f2fea711 changed that derivation to `.pdf` for about 22h and added a test asserting the bug; 2400dbd1 reverted it.
   - `_prepare_bodies` writes `body:`+body_key entries into the persisted raw-bodies routing index (raw_storage.py:948-966). Scan that index and anything else persisted in the window (Oct 22 20:16 to Oct 23 18:44) for `.pdf` keys.
   - Keep the golden test (test_raw_archive_schema_tuning.py:190).
4. **Dormant raw-body deletion.** `migrate_pdf_bodies_to_uncompressed(delete_gzip=True)` deletes the canonical `.gz` whenever a `.pdf` sibling merely exists, with no sha check of the sibling (raw_storage.py:313-316). Today this is a no-op only because no store implements `delete`. Delete the option.
5. **Restricted-text exposure (ct-a3le, ct-5yof).** A C5 subset read exports expired text (analysis/export.py:83-88). This matters only once exports are published.

**Low or irrelevant here (derived data, rebuildable from raw):**
- ct-2yl5, ct-bwac, ct-gi01 (including the Pages ImportError), ct-6rnk (regression), ct-3ttc, ct-h23e, ct-s9p2 and ct-0odd.
- Also the a1aa oracle-only performance items (ct-07eg, ct-qxqp, ct-3lz2).
