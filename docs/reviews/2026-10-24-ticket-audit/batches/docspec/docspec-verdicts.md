## Cross-cutting findings (not owned by one ticket)

1. **Production code that no test runs (HIGH).** 60 sites in `src/` are compiled only under `#[cfg(all(not(test), not(feature = "test-util")))]`; 53 came from `b4b827d` (pushed Oct 24, after the qualified `c949c67` pin, empty commit body), 17 more moved/added by `d05df4d`. `scripts/check` runs only `cargo test --all-features` (test-util on), so none of these paths are exercised. They include:
   - Deferred lifecycle commits: `src/catalog.rs:765-790` buffers every lifecycle commit (phase records, protections, attempts) in memory during a Build/Update started at `src/engine/pipeline.rs:510-518`; nothing is durable until the final commit. This breaks the AGENTS.md rule "preserve expensive completed phases across cancellation, worker loss" in the shipped binary while crash-recovery tests (test-util) prove it on a different code path. `src/engine/pipeline.rs:111-112` discards flush errors (`let _ = ...flush_deferred(...)`).
   - Consumer dataset names hard-coded in the engine: `src/engine/release_check.rs:86-89` and `:226-229` skip input checks, including `VerificationLevel::Deep`, for datasets named `catalog-*`, `raw-*`, `obs-*`, `source-observations-*`; `src/engine/pipeline.rs:317-322` uses the same prefixes for a fast path. This is domain policy inside the mechanism layer, and a requested deep check is silently narrowed.
   - The `GuardedCatalog` head re-load before commit is test-only (`src/catalog.rs:696-700`).
   Risk to verify, not proven: protections that exist only in memory while objects are being written are invisible to `live_retained_closure`, so a concurrent `compact_lifecycle` reclaim could race an in-flight deferred operation.
2. **Docs drift.** `docs/STATUS.md` was last changed in `b0dc9a7` (Oct 18). None of the ss-55jg features are recorded there. `README.md:121` still says "Remote computed and related groups remain outside the supported profile", but `src/engine.rs:435-446` now admits Refresh/Evidence/Backfill on remote.
3. **Consumer pin.** ct pins `c949c67` (`ct:packages/docspec_client/src/docspec_client/models.py:16-25`, features `('remote',)`). The P0 fixes (ss-cnsn, ss-e2it, ss-mn81) and all CS300 refactors are after that pin, so they are unqualified for the consumer.
4. **`ss-proc` is not a ticket.** No commit or ticket contains the exact token (`git log --all -E --grep='\bss-proc\b'` is empty in both repos). A substring grep matches "cro**ss-proc**ess" in `6a9775a` ("fix(intake,http,write): resolve cross-process fence clock skew, IPC staging cleanup, and DirectParquet budget admission"). That commit added the wall-clock deadline to SourceFence (`src/engine/intake.rs`), changed IPC staging cleanup and changed DirectParquet budget admission (`src/engine/write/build.rs`). It is ss-vfm6/ss-8tpu follow-up work.
