# Degree wording and local amendment references

Decision: preserve the recurring components of local amendment filenames rather
than leaving degree wording and explicit target text buried in name assumptions.

Hypothesis: shared, bounded source rules can expose literal degree wording,
adjacent local numbers and an explicit `to` target before another degree clause.
The same family uses `S.__` / `S___` placeholders; preserve the printed measure
type and placeholder without inventing a bill number or Congress. Reuse the
measure vocabulary, protected spans and fallback machinery.

Arms: frozen native and strict outputs in `drafts-final`, accepted House extraction
in `malformed-dates-remainders`, and this deliberate local-filename bundle.
Hold native code, official guide definitions, strict records and the retained
333,368-name corpus constant. Discovery contains 424 filenames and 447 degree
phrases, mainly Senate Agriculture, Foreign Relations and Energy sources. These
are candidate counts, not gains or proof of what the files contain.

Fields describe literal source syntax. Degree wording receives its printed
ordinal, not the guide-specific interchamber `HAmdt2` meaning. Local numbers stay
separate from official amendment identifiers. `to_Shaheen_1st_Degree_3` retains
target wording and its own degree/number clause without resolving a person or
creating a verified amendment relationship. Long digit strings are not split
into an inferred number and date. Existing dates, UUIDs and source IDs take
precedence over a new local-number assumption. Bare degree wording in another
context, such as first-degree murder, must not assert an amendment role.

Cases: actual first/second-degree pairs, absent local numbers, leading zeros,
revised/modified suffixes, UUIDs, hanging pdf, compound targets, measure
placeholders and independent amendment/agenda numbers. Include constructed
word boundaries, malformed ordinals, protected witness IDs, date-shaped numeric
suffixes, unrecognized target text and multiple references.

Adopt only if useful literal fields survive with exact spans, all strict outputs
and prior vocabulary meanings remain unchanged, and every displaced field has
an explicit source-based explanation. Check additions and losses in the full
comparison, not just discovery matches. Preserve original spellings and prior
candidate readings; do not infer identities, missing numbers or event dates.

Reuse the existing comparison and omission audit. Each full run is bounded to
30 minutes; no document downloads. Reused corpus and constructed fixtures are
development evidence. Retain failed runs and revise this note explicitly when
new evidence changes the intervention.

First-candidate revision: the full tests found duplicate placeholder fields when
a later whole-slot rule already supplied the same type/placeholder. Keep that
existing observation and omit the redundant general search. The full field audit
also found two lost `pdf` fallback suffixes in `pdf-1` filenames when a generic
identifier gained a local-number role. Reuse the fallback's remaining fields while removing only the
duplicate generic-number interpretation. Keep the first run and failure logs;
these are shared precedence/refinement fixes, not filename exceptions.
The first focused suffix assertion expected a combined `pdf-1` field. Direct
inspection of the baseline showed separate `pdf` and `1` fields; the corrected
test checks that existing split. Recursive fallback must also accept the new
local-number refinement after its generic-number field is removed.
