# Capture storage code should not stop the nightly as a model definition change

Since PR 203 (b15dca5b), packages/congress_api/src/congress_api/retention/body_store.py is in _definition_hashes because archive_model.py imports pdf_cover_evidence.py, which imports body_store. So a capture storage fix (PR 211, R2 create reconcile) stops the next night at gate 1 for a cause record although it cannot change model output. Narrow the import (pdf_cover_evidence should depend on a read-only body reader, not the R2 write adapter) or hash only what the model reads. Check with .github/scripts/definition-change.py --base <commit before PR 211>: a storage-only change must report unchanged.
