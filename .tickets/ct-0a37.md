# Qualify the metadata improvements across retained sources and both consumers

Close the epic on demonstrated user outcomes, not on parser tests or populated columns alone.

User value: users receive improvements that are traceable to real source pages and work consistently through the released data interfaces.

Evidence: docs/experiments/extruct-metadata-20261030/report.md and summary.json. Full extraction and comparison artifacts are under output/extruct-metadata-20261030/ (local, Git-ignored); preserve portable fixtures and manifests needed for tests rather than relying solely on these local paths.

## Design

Run the full path from a frozen retained input selection through extraction, selection, mapping, publication, site, and MCP at one recorded integrated revision. Include the listing cohort, marked testimony/article examples, conflicting metadata, repeated keys, no-metadata pages, HTTP error pages, missing capture context, and all known parser failure classes.

Use portable fixtures/manifests for essential acceptance and a measured retained-corpus run for coverage. Record the audit baseline separately from the new snapshot; reconcile changed counts instead of forcing historical totals. Prepare a concrete locally validated release candidate. Local success does not establish a deployed release; a later publication, if performed, requires its own selector/readback evidence under the existing workflow.

## Acceptance Criteria

- Demonstrate corrected row/date association, explicit PM conflicts, cleaner selected content, useful descriptions, and separate event/published/updated dates through actual site and MCP reads.
- Compare unique source/body/entry denominators, selection/fallback/error counts, and preserved identities; explain every acceptance gap and do not count generic metadata as new facts.
- Verify all selected facts can be traced to original body hashes and source selectors; original source retention and unrelated records remain intact.
- Report selective replay cost and publication/browse size impact using measured work, without a blanket full-rebuild or performance claim.
- Save a concise completion receipt naming code/input/release pins, checks performed, remaining limitations, and whether publication was local-only or independently verified live.
