# Fix critical and high vulnerabilities in shipped dependencies

Start with the Congress Explorer MCP dependency that reads saved PDF text. The MCP 0.6.1 source still pins `pypdf==6.19.0` in the app's package and lockfile. Keep broader dependency triage as separate work outside Phase 2. The November 2 Dependabot count of 126 advisories is historical, including seven critical and 55 high.

## Root cause (2026-11-05)

The hosted image installs the app-local lock. On a cache miss, `get_document(section="text")` verifies the selected saved body and calls `PdfReader` and `extract_text` on the downloaded PDF. That makes the affected pin reachable through a shipped feature. Existing GitHub advisory evidence identifies affected versions and fixes through 6.21.4. A production incident has not been established.

The request deadline is a separate execution concern. It can return a timeout while the abandoned decoder thread keeps running. The decoder checks deadlines between calls, so a stuck call can outlast that check. Upgrading the library addresses the known vulnerabilities. A hard interruption requirement would need a separate execution boundary.

## Smallest useful change

Update the MCP app's `pypdf` requirement and lock to a compatible release that resolves the cited advisories. Verify the existing saved-PDF text path in the rebuilt runtime. Reuse the selected archive release and valid body-hash cache entries. The app-local lock is independent of the root archive parser pins.

## Acceptance Criteria

- Record the affected shipped component or development-only disposition for each advisory in scope. Fix critical and high issues that affect shipped code and record the resulting dependency versions.
- For the MCP slice, verify the installed dependency and a benign saved-PDF text read with the existing response and body limits. Record candidate and deployed runtime evidence separately.
- When a separate Python update moves the root `uv.lock`, coordinate the parser-version transition and record which readings can be reused. Reread only affected inputs when required.
