# Prevent cursor regression across releases and checkpoint tearing in PageDrain

Cursor monotonicity currently holds only within a single in-memory PageDrain instance and only when completed_until strictly decreases:
1. storage/control.py:140-154 (ControlStore.activate_checkpoints) unconditionally overwrites active_checkpoints on conflict, and PageDrain (adapters/cursors.py:47-51) does not seed from the control store's active cursor. A later backfill or out-of-order release with an older completed_until regresses active_checkpoints in SQLite.
2. adapters/cursors.py:69-78 (PageDrain._advance): when a subsequent page has completed_until == self._completed_until, it overwrites self._checkpoint_ref; when a subsequent page has until=None after self._completed_until was already set, it overwrites self._checkpoint_ref while keeping the earlier page's self._completed_until, creating a torn hybrid checkpoint.

## Design

1. In PageDrain._advance(ref, until), only advance when completed_until strictly advances beyond self._completed_until (or when self._completed_until is None); never overwrite a timed checkpoint's ref with an untimed (until=None) checkpoint or an equal-window older page. Allow PageDrain to optionally accept the prior active checkpoint for connector_key.
2. In ControlStore.activate_checkpoints, compare the incoming completed_until against the existing active_checkpoints.completed_until (using parse_instant) and do not regress the active cursor when an older backfill cycle is published.

## Acceptance Criteria

- Publishing a backfill release whose checkpoint has completed_until earlier than the connector's active cursor preserves the newer active cursor in ControlStore.active_cursor() while still recording the release's own checkpoint in the release record.
- Feeding PageDrain a page with completed_until=T2 followed by a page with completed_until=None or completed_until=T2 (or T1 < T2) does not tear or overwrite the checkpoint_ref for T2.


## Notes

**2026-10-20T17:30:45Z**

ControlStore.activate_checkpoints enforces cross-cycle monotonicity inside the write transaction; PageDrain no longer tears or regresses timed checkpoints on untimed/equal/older pages. Cursor tests pass.
