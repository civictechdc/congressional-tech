# Search document, testimony, and caption text across Congress MCP

`search_documents` matches metadata. [ct-o7t4](ct-o7t4.md) reads and searches one known body. Add search across the supported corpus and reuse those verified text readings and the caption cues from [ct-4kuo](ct-4kuo.md).

## Acceptance Criteria

- Search supported document bodies, prepared testimony, and complete caption tracks. Filter by committee, date, speaker where attribution is available, and document type. Return bounded snippets with source references and page, offset, or cue locations.
- Report indexed coverage by material kind and release, including unreadable or unavailable content. Preserve source roles and speaker uncertainty. Keep existing metadata search behavior available.
- Demonstrate a body-only phrase missed by metadata search, each filter, and matching caption cues. Record indexing and query cost for the selected corpus, reuse unchanged verified bodies, and exercise a new release with changed and retired references.
