# Substitute wording inside legislative fields

Decision: expose printed substitute markers, explicit targets and local numeric
components that remain inside already-recognized legislative source fields.

Hypothesis: anchored target shapes and bounded literal markers recover useful
metadata without interpreting ordinary words containing ANS or AINS. Reuse the
native substitute-file distinction between marker, target wording and reference.
Keep every original subject and amendment token, including complete local IDs.
Local numeric components do not become bill or amendment sequence numbers.

Arms: saved native outputs in drafts-final and saved House outputs in
structured-slots-reviewed versus the candidate House extractor. Freeze source
hashes, strict behavior, guide meanings and the 333,368-basename inventory.

Cases: all 77 ANStoCommitteePrint subjects; observed spelled-out headings,
ANStoHR/ANStoHRes targets, ANS1toHR targets, standalone and delimited markers,
and local forms such as 1toANS, ANS_01 and 033_ANS. Include actual ordinary-word
controls (TransHUD, WASSERMANSCHULTZ, Transportation) and constructed misleading
word boundaries, unsupported prefixes, ordinals, missing bill types, identifiers
and non-legislative names. The inspected inventory contains 835 relevant field
occurrences, including false substring hits; that is not a positive-label set.

Acceptance: raw spans and all prior useful fields remain available, strict
results stay unchanged, no existing code meaning is removed, and targets do not
borrow a bill type or Congress from adjacent numbers. Markers without a catalog
definition remain literal; source documents are not verified by filenames.
Inspect every changed field family and all removed source signatures. Save
negative examples and failed attempts. Run one full comparison after targeted
checks pass; repeat only for a material correction. Bound comparisons to the
retained corpus and 30 minutes. No downloads. Reused cases are development
evidence, not an independent accuracy benchmark.
